BASICS:
- Uses indentation (4 spaces) to define code scope
- Check version: python --version (in command prompt)
- Interactive mode: Type "py" in cmd, then exit() to quit

COMMENTS:
- Single line: # comment
- Multi-line: ''' comment text '''

DATA INPUT:
- input() function always returns a string
- Python is dynamically typed (no type declaration needed)

TYPE CHECKING & CASTING:
- Check type: type(variable) => returns data type
- Cast to string: str(value)
- Cast to integer: int(value)
- Cast to float: float(value)
- Cast to list: list(tuple_or_sequence)
- Cast to tuple: tuple(sequence)
- Cast to dict: dict(key=value, ...)
- Cast to set: set(sequence)
- Cast to boolean: bool(value)

VARIABLE NAMING RULES:
- Start with letter or underscore (_)
- No numbers at start
- Case-sensitive
- Avoid Python keywords
- Naming conventions:
  * camelCase: myVariableName
  * PascalCase: MyVariableName
  * snake_case: my_variable_name

VARIABLE SCOPE:
- Global: declared outside functions, accessible everywhere
- Local: declared inside functions, accessible only within function
- Use "global" keyword to make local variable global

UNPACKING:
- Assign multiple values at once
- Example: x, y, z = ["apple", "banana", "cherry"]

OPERATORS:
- Arithmetic: +, -, *, /, //, %, **
- Comparison: ==, !=, <, >, <=, >=
- Logical: and, or, not
- Assignment: =, +=, -=, *=, /=, //=, %=, **=
- Bitwise: &, |, ^, ~, <<, >>
- Identity: is, is not
- Membership: in, not in

CONTROL FLOW:
- Conditional: if, elif, else
- Loops: for, while
- Loop control: break, continue, pass
- Exception handling: try, except, else, finally

FUNCTIONS:
- Definition: def function_name(parameters):
- Return values: return statement
- Default parameters: def func(x=5):
- *args: variable positional arguments
- **kwargs: variable keyword arguments
- Lambda: lambda x: x + 2 (anonymous functions)

COLLECTIONS:
- List: mutable, ordered, allows duplicates
- Tuple: immutable, ordered, allows duplicates
- Set: unordered, unique values, mutable
- Dictionary: key-value pairs, unordered (Python 3.7+: ordered)

BUILT-IN FUNCTIONS:
- print(), len(), type(), isinstance()
- min(), max(), sum(), abs()
- sorted(), reversed(), enumerate()
- zip(), map(), filter()
- all(), any(), range()

KEY DIFFERENCES:
- Python: Strong typing distinction (int vs float)
- JavaScript: Number type for all numeric values
- Python: Immutable tuples & frozensets
- JavaScript: Limited immutable alternatives


STRINGS:
- Immutable: Cannot modify after creation
- Access: Use indexing and loops to iterate through characters

EXAMPLE:
 for x in "banana":
  print(x)

LENGTH FUNCTION:
- Keyword: len()
- Returns the number of characters in a string
- Example: len("selva") => 5
- Can be used with: string, list, tuple, set, dict

EXAMPLE:
 length = len("hello")  # Store in variable

MEMBERSHIP OPERATORS ("in" and "not in"):
- Check if a value exists in a sequence
- Returns: Boolean (True or False)
- Works with: string, list, tuple, set, dict

EXAMPLE:
 myStr = "happy birthday!"
 print("birthday" in myStr)      => True
 print("goodbye" not in myStr)   => True


STRING SLICING:
- Syntax: string[start:end:step]
- start: beginning index (inclusive, default 0)
- end: ending index (exclusive)
- step: increment between indices (default 1)

EXAMPLES:
 Name = "Hello World "
 print(Name[2:5])      => "llo" (index 2 to 4, index 5 excluded)
 print(Name[2:])       => "llo World" (from index 2 to end)
 print(Name[:4])       => "Hell" (from start to index 3, index 4 excluded)
 print(Name[-2:])      => "ld" (last 2 characters)
 print(Name[:-2])      => "Hello Wor" (all except last 2 characters)
 print(Name[-4:-2])    => "Wo" (from index -4 to -3, -2 excluded)
 print(Name[::2])      => "HloWrd" (every 2nd character. it basically adds step in slicing.)
 print(Name[::-1])     => "dlroW olleH" (reverse string)

KEY POINTS:
- Negative indices: -1 is last character, -2 is second last, etc.
- Slicing returns new string (strings are immutable)
- Out of range indices don't cause errors


*** NOTE: STRING METHODS RETURN NEW VALUES NOT UPDATING THE ORIGINAL STRING ***

STRING METHODS:

CASE CONVERSION:
- name.upper()           => "HELLO WORLD" (converts to uppercase)
- name.lower()           => "hello world" (converts to lowercase)
- name.swapcase()        => "hELLO wORLD" (swaps case of each character)
- name.capitalize()      => "Hello world" (first character uppercase, rest lowercase)
- name.title()           => "Hello World" (first character of each word uppercase)

WHITESPACE HANDLING:
- name.strip()           => "Hello World" (removes whitespace from both ends)
- name.lstrip()          => "Hello World " (removes whitespace from left end only)
- name.rstrip()          => " Hello World" (removes whitespace from right end only)

SPLITTING & JOINING:
- name.split(" ")        => ["Hello", "World"] (splits string into list by delimiter)
- name.rsplit(" ")       => ["Hello", "World"] (splits from right, useful with maxsplit)
- name.join(list)        => "Hello-World" (joins list elements with string as separator)
  EXAMPLE: "-".join(["Hello", "World"]) => "Hello-World"

SEARCHING & REPLACING:
- name.replace("o", "0") => "Hell0 W0rld" (replaces all occurrences)
- name.find("World")     => 6 (returns index of first occurrence, -1 if not found)
- name.rfind("o")        => 7 (returns index of last occurrence)
- name.index("World")    => 6 (like find(), but raises error if not found)
- name.rindex("o")       => 7 (like rfind(), but raises error if not found)
- name.count("l")        => 3 (counts occurrences of substring)

CHECKING CONDITIONS:
- name.startswith("He")  => True (checks if string starts with substring)
- name.endswith("ld")    => True (checks if string ends with substring)
- name.isspace()         => False (checks if all characters are whitespace)
- name.isalpha()         => False (checks if all characters are alphabetic)
- name.isdigit()         => False (checks if all characters are digits)
- name.isalnum()         => False (checks if all characters are alphanumeric)
- name.islower()         => False (checks if all characters are lowercase)
- name.isupper()         => False (checks if all characters are uppercase)

FORMATTING:
- name.format()          => formats string with placeholders
  EXAMPLE: "My name is {}".format("John") => "My name is John"
  EXAMPLE: "{}+{}={}".format(2, 3, 5) => "2+3=5"

STRING CONCATENATION:
- Use "+" operator: "Hello" + " " + "World" => "Hello World"

F-STRINGS (Formatted String Literals):
- Syntax: f"text {variable} text"
- Supports expressions, function calls, formatting

EXAMPLES:
  name = "Emili"
  age = 25
  txt = f"My name is {name}"              => "My name is Emili"
  txt = f"Next year I'll be {age + 1}"    => "Next year I'll be 26"
  
  def get_price():
      return 200
  
  txt = f"The price is {get_price():.2f} dollars"  => "The price is 200.00 dollars"

ESCAPE CHARACTERS:
- Use backslash "\" to escape special characters in strings

COMMON ESCAPE SEQUENCES:
- \n    => newline
- \t    => tab (horizontal indentation)
- \r    => carriage return
- \b    => backspace
- \\    => backslash
- \"    => double quote
- \'    => single quote
- \0    => null character

EXAMPLES:
  print("Hello\nWorld")    => Hello
                              World
  print("Name:\tJohn")     => Name:	John
  print("Path: C:\\Users") => Path: C:\Users
